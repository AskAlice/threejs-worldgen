# Imported GitHub issues

All 88 issues from [AskAlice/threejs-worldgen](https://github.com/AskAlice/threejs-worldgen) (open and closed) are tracked locally, one file each.

## Layout

`.scratch/<package>/<milestone>/issues/NN-slug.md`

- Every issue has exactly **one** ticket file: under its first package alphabetically, or `shared/` when it has no `package:*` label.
- The milestone title is a subdirectory (`no-milestone` when absent).
- Tickets are numbered `01`–`88` once, in milestone order then GitHub order. Numbers are not contiguous inside one directory because each ticket lives in one place.
- Every package/milestone also has an `INDEX.md` linking the tickets that touch it, including ones whose canonical file lives under another package. Nothing is duplicated; edit the ticket behind the link.
- `Status:` follows this repo's triage vocabulary; closed issues are `resolved`.
